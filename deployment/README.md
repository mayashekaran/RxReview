# RxReview

RxReview is a pharmacist-led diabetes discharge-review
decision-support prototype.

It combines:

- calibrated readmission-risk ranking,
- medication complexity,
- pharmacist-capacity prioritization,
- cost/value scenario analysis,
- and RAG-based discharge guidance grounded in AHRQ/CMS material.

## Intended Use

RxReview supports prioritization for pharmacist review.

It does not prescribe medications, recommend doses,
or replace clinical judgment.
